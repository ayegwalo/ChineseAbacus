# ChineseAbacus
A Java application that simulates a Chinese abacus. Test your application by performing the four basic math operations (addition, subtraction, multiplication, and division) on your abacus.


- Simulates a traditional Chinese abacus with rods and beads
- Supports:
  - Addition
  - Subtraction
  - Multiplication
  - Division
- Object-oriented design (modular classes)
- Graphical User Interface (GUI) built with Java Swing


**HOW TO RUN**
javac *.java
java AbacusApp


**Educational Purpose**
This project demonstrates:
How to apply object-oriented programming (OOP) concepts to model physical systems
Basic GUI design using Java Swing
Simulating historical computing tools in modern code
